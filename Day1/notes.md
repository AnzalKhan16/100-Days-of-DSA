## We are given an array and a target value.
## We need to return the indices of two numbers whose sum equals the target.”

Example:

nums = [2, 7, 11, 15]
target = 9

Output:

[0, 1]

because:

2 + 7 = 9

### Approach Used

“I am using the Hash Map approach to optimize the solution.”

A hash map helps us:

store elements quickly
search elements in constant time

### Average lookup complexity:
O(1)
